# Bu-Chill - Free Movies, TV Shows & Live TV Streaming 🍿

🍿**Bu-Chill**🍿 is a next-generation streaming platform built with Next.js 15, Tailwind CSS, HeroUI, and Supabase. It offers a seamless, fast viewing experience with personalized AI recommendations, 24/7 Live TV channels, watch progress tracking, and watchlists.

## Key Features

- **🍿 Free & Fast Streaming**: Access a vast catalog of movies, TV series, and live channels.
- **✨ Bu-Chill AI Concierge**: Built-in intelligent AI streaming assistant analyzing your watch taste.
- **📺 24/7 Live TV Channels**: Watch live sports, news, and entertainment streams.
- **⏱️ Smart Progress & History**: Automatically resumes where you left off with zero-egress caching.
- **🌗 Dark Cinema Theme**: Clean, responsive layout designed for desktop, tablet, and mobile.
- **🔐 Instant Authentication**: Supabase Auth with email & Google Single Sign-On (SSO).
- **📲 Progressive Web App (PWA)**: Installable directly on desktop and mobile devices.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/) & [HeroUI](https://heroui.com/)
- **Backend & Auth**: [Supabase](https://supabase.com/)
- **State & Data**: TanStack Query
- **Data Source**: The Movie Database (TMDB) API

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/bereket-09/bu-chill.git
cd bu-chill
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.
